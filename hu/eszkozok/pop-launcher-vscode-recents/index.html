Legutóbbi VS Code projektek megnyitása a Pop!_OS launcherből

Ugorj vissza bármelyik projektbe anélkül, hogy előbb megnyitnád a VS Code-ot. Nyomd meg a Super billentyűt, írd be, hogy vc és a mappanév egy részét, és megnyílik, akkor is, ha WSL, SSH vagy konténeres mappáról van szó.

  • pop-launcher plugin
  • Rust
  • x86_64 és ARM64
  • MIT licenc
Megnézem a GitHubon Legfrissebb kiadás

Mit tud?

  • A VS Code-ban legutóbb megnyitott mappák és workspace-ek között keres.
  • A távoli projekteket (WSL, SSH, konténer) is megtalálja.
  • Az ikonok az asztali ikontémából jönnek, így a találatok illeszkednek a rendszer többi részéhez.
  • A már nem létező helyi mappák rejtve maradnak.
  • Egyetlen statikus bináris: nem kell hozzá Node.js vagy Rust.

Telepítés

Kell hozzá a pop-launcher, és hogy a code parancs benne legyen a PATH-ban. Töltsd le a legfrissebb kiadást a plugin mappába:

mkdir -p ~/.local/share/pop-launcher/plugins
curl -fsSL "https://github.com/Silureth/pop-launcher-vscode-recents/releases/latest/download/vscode-open-recent-$(uname -m).tar.gz" \
  | tar -xz -C ~/.local/share/pop-launcher/plugins

Utána indítsd újra a pop-launchert. A launcher következő megnyitásakor újraindul:

pkill pop-launcher

Frissítéshez futtasd le újra mindkét lépést. A beállításaid megmaradnak.

Beállítások

Az alapértékekkel azonnal működik. Ha módosítanád őket, másold a config.example.json fájlt config.json néven a plugin mappájába:

BeállításAlapértékMit csinál?
always_open_in_new_windowtrueÚj VS Code ablakban nyitja meg a találatot
hide_deleted_entriestrueKihagyja a már nem létező helyi mappákat
vscode-cli-additional-args[]Plusz argumentumok a code parancsnak, pl. ["--profile", "Work"]

A vc kulcsszót is átírhatod a plugin.ron fájlban. Ha a régebbi, Node.js-es verziót használtad, a README leírja, hogyan frissíts (angolul).
