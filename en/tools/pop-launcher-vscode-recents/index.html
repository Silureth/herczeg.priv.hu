Open recent VS Code projects from the Pop!_OS launcher

Jump back into any project without opening VS Code first. Press Super, type vc and part of the folder name, and it opens, even if it's a WSL, SSH or container folder.

  • pop-launcher plugin
  • Rust
  • x86_64 & ARM64
  • MIT license
View on GitHub Latest release

What you get

  • Lists the folders and workspaces you recently opened in VS Code.
  • Remote projects (WSL, SSH, containers) are included too.
  • Icons come from your desktop icon theme, so results match the rest of your system.
  • Local folders that no longer exist are hidden.
  • A single static binary: no Node.js, no Rust toolchain needed.

Install

You need pop-launcher and the code command in your PATH. Download the latest release into your plugins folder:

mkdir -p ~/.local/share/pop-launcher/plugins
curl -fsSL "https://github.com/Silureth/pop-launcher-vscode-recents/releases/latest/download/vscode-open-recent-$(uname -m).tar.gz" \
  | tar -xz -C ~/.local/share/pop-launcher/plugins

Then restart pop-launcher. It starts again the next time you open the launcher:

pkill pop-launcher

To update, run both steps again. Your settings are kept.

Settings

The defaults work out of the box. To change them, copy config.example.json to config.json in the plugin folder:

OptionDefaultWhat it does
always_open_in_new_windowtrueOpen entries in a new VS Code window
hide_deleted_entriestrueSkip local folders that no longer exist
vscode-cli-additional-args[]Extra arguments for code, e.g. ["--profile", "Work"]

You can also change the vc trigger word in plugin.ron. If you used the older Node.js version, the README explains how to upgrade.
