Open Remmina connections from the Pop!_OS launcher

Stop clicking through the Remmina window to find a server. Press Super, type rem and part of a name, and the RDP, VNC or SSH session opens.

  • pop-launcher plugin
  • Rust
  • x86_64 & ARM64
  • MIT license
View on GitHub Latest release

How it works

  • Each result shows the connection name with its group, protocol and user@server. You can search by any of them: rem office db or rem 10.0.1.
  • With no search text, your most recently used connections come first.
  • It reads only the name, group, protocol, server and username from your .remmina files. Passwords are never touched.
  • It finds connections in native, Flatpak and legacy Remmina installs, and in a custom folder if you set one in Remmina's preferences.

Install

It's a single static binary, so there's nothing else to install. Download the latest release into your plugins folder:

mkdir -p ~/.local/share/pop-launcher/plugins
curl -fsSL "https://github.com/Silureth/pop-launcher-remmina-quick-connect/releases/latest/download/remmina-quick-connect-$(uname -m).tar.gz" \
  | tar -xz -C ~/.local/share/pop-launcher/plugins

Then restart pop-launcher. It starts again the next time you open the launcher:

pkill pop-launcher

To update, run both steps again. Your settings are kept.

Flatpak Remmina

Copy config.example.json to config.json in the plugin folder and set the launch command:

{ "remmina_command": ["flatpak", "run", "org.remmina.Remmina"] }

You can also change the rem trigger word in plugin.ron. The README has the details.
