Twin Blades on modern PCs: Resanctified

Twin Blades came out for Windows Phone 7 in 2010. The phones are gone and the game can no longer be bought or installed. Resanctified is a free, non-commercial port that keeps it playable on current Windows and Linux PCs.

  • C#
  • .NET 10
  • MonoGame
  • Game preservation
Download v1.0 View on GitHub

What the port does

  • Moves the original XNA game to .NET 10 and MonoGame DesktopGL, so it runs natively on Windows and Linux (x64).
  • Releases are self-contained: no .NET install needed. The Linux build also bundles SDL2 and OpenAL.
  • An optional HD texture pack at twice the original resolution, upscaled from the original art. The game falls back to the original textures when HD is off.
  • A resizable window, starting at 960×640.

Download and play

Get the archive for your system from the latest release and unpack it. Keep the whole folder together, since the game loads its content from next to the executable.

Linux

tar -xzf Resanctified-v1.0-linux-x64.tar.gz
./Resanctified-linux-x64/Resanctified

If the archive was repacked on Windows and the executable bit got lost, run chmod +x Resanctified.

Windows

Unzip Resanctified-v1.0-win-x64.zip and double-click Resanctified.exe.

Window size and saves

Start with a bigger window:

./Resanctified --window 1440x960

Saves and settings go to ~/.local/share/Resanctified on Linux and %LOCALAPPDATA%\Resanctified on Windows.
